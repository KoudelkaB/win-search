# File Search Manager ヘルプ

File Search Manager には 2 つの主要な入力欄があります。

- **フィルター** は名前、フォルダー、パス、選択したディレクトリでファイル一覧を絞り込みます。
- **検索** は現在フィルターされているファイルの中身を検索します。

結果一覧はキーボード操作を前提に設計されています。一覧にフォーカスがあるとき、**ヒント** パネルには選択項目に対して現在使えるコマンドが表示されます。

## インデックスと権限昇格

起動時、File Search Manager は準備できたドライブを読み込み、ファイルシステムの変更を監視します。各ドライブは独立して読み込まれるため、低速なネットワークドライブが他を遅らせることはありません。

既定では NTFS ドライブのみをインデックス化します。他のファイルシステム（ネットワーク マウント、FAT の USB メモリ）は高速な MFT 読み取りを利用できず、1 ファイルずつたどると読み込み全体を占有しかねないためです。ステータスバーの **💽 ドライブ…** ボタンで、インデックス化するドライブを正確に選べます。チェックを外したドライブはスキャンも監視もされません。

NTFS ドライブでは、NTFS のマスター ファイル テーブルを読むのが最速です。File Search Manager は次のいずれかの方法でそれを行います。

- Windows サービス: 確認は一切ありません。インストーラーで既定で選択されています。
- 権限昇格ヘルパー: アプリの実行ごとに UAC の確認が 1 回。サービスがない場合は起動時に提示され、インデックス化をすぐ開始できます。サービスがある場合は、管理者権限が実際に必要になる最初の操作 — `A` キー、管理者だけが読めるファイルの読み取り、書き込みが保護された項目の名前変更や日時の変更 — まで提示されません。**🌐** の隣の **🛡** ボタンを使うと、代わりに起動時に確認します。
- 昇格した状態のアプリ: File Search Manager を管理者として実行します。

いずれも利用できない場合、File Search Manager はフォルダーの巡回に切り替えます。アプリは引き続き動作しますが、初回の読み込みは遅くなることがあります。

サービスはインデックス化のために読み取り専用で動作します。MFT のデータをデスクトップ アプリに提供し、名前は `WinSearchService` です。

## フィルターの構文

フィルターの語は空白で区切ります。空白を含む語やパスは引用符で囲みます。

名前の一致:

- `report` は `report` を含む名前に一致します。
- `:report` は `report` で始まる名前に一致します。
- `report:` は `report` で終わる名前に一致します。
- `:report:` は名前がちょうど `report` のものに一致します。
- `.pdf:|.docx:` は `.pdf` または `.docx` で終わる名前に一致します。
- 複数の語は AND で結合されるため、`report .pdf:` は `report` を含み `.pdf` で終わる名前を検索します。

フォルダーの一致:

- `src\` は直上の親フォルダー名が `src` の項目に一致します。
- `src\\` は完全パスのどこかに `src` を含む項目に一致します。
- 名前のアンカーはパスの各要素に適用されるため、`:src:\\` はパス内の任意の場所に名前がちょうど `src` のフォルダーを持つ項目を検索します。
- `"C:\Work"` は `C:\Work` の直下にある項目に一致します。
- `"C:\Work\\"` は `C:\Work` 配下の項目に再帰的に一致します。

履歴:

- `Ctrl+Left` と `Ctrl+Right` でフィルター履歴をたどります。
- `Down` で候補を表示します。
- `Del` で選択中の候補を削除します。
- 候補を開くときに `Ctrl` を押したままにすると、使用頻度順ではなく新しい順の履歴を使います。

### 固定フィルター

- **📌 固定…** をクリックすると、固定フィルターの行に編集可能なタブが追加されます。その場で名前を入力して `Enter` を押します。`Esc` で取り消します。
- 名前付きフィルターをクリックすると、保存された式が復元されます。有効な名前付きフィルターは強調表示されます。
- 名前付きフィルターを右クリックすると、現在の式から更新、その場で名前変更、固定解除ができます。
- 固定フィルターはアプリの起動時に復元されます。

**エクスポート…** はすべての固定フィルターと宛先バスケットの項目を 1 つの JSON 設定ファイルに保存します。**インポート…** は設定ファイルを検証し、確認のうえ、現在の固定フィルターと宛先をその内容で置き換えます。

## 内容の検索

**検索** に語を入力して `Enter` を押します。

エンコードの選択:

- `UTF-8` は UTF-8 でエンコードされたテキストを検索します。
- `UTF-16` は UTF-16 リトルエンディアンでエンコードされたテキストを検索します。
- `HEX` は空白区切りの 16 進数で書かれたバイト列を検索します。例: `48 65 6C 6C 6F`。

**大文字と小文字を区別しない** チェックボックスはテキスト検索に適用されます。

内容検索後の結果の色:

- 緑: 内容が見つかりました。
- 赤: 内容が見つかりませんでした。
- 黒: 項目が検索されていない、または検索がクリアされました。
- 青: フォルダー。

検索欄で `Enter` 以外を入力すると、現在の内容検索の結果状態はクリアされます。

## マウス操作

- 結果をクリック、Ctrl+クリック、Shift+クリックで単一項目または範囲を選択します。
- ファイル名やフォルダー名をダブルクリックすると、その項目に絞り込みます。
- フォルダー列をダブルクリックすると、その項目を選択した状態でエクスプローラーが開きます。
- 結果を Ctrl + 右クリックすると、Windows の既定の操作で開きます。
- 列見出しをクリックすると、その列で並べ替えます。
- 選択項目を右クリックすると、開く、動的なアプリで開く、クリップボード、名前変更、圧縮、削除の操作が表示されます。
- **宛先バスケットに追加** は右クリックした列に従います。名前なら選択項目を、フォルダーならその親フォルダーを追加します。対応するパスが対応外の宛先である場合や、すでにバスケットにある場合は表示されません。
- 名前列からドラッグすると、選択したファイルやディレクトリを別のアプリへ送れます。
- フォルダー列からドラッグすると、選択項目の親フォルダーを送れます。
- 名前列のディレクトリ、またはフォルダー列の親パスにファイルをドロップできます。コピー、移動、シンボリック リンク、ハード リンクから選びます。
- 実行可能ファイルの名前セルにファイルをドロップすると、ドロップしたパスを引数として起動します。
- ファイルのドロップはエクスプローラーの既定に従います。同じボリューム上の 1 つのフォルダーは移動、別のボリュームはコピーになります。`Ctrl` でコピー、`Shift` で移動、`Alt` でシンボリック リンクです。宛先が複数の場合はコピーになります。

## 実用例

- **ディスク容量を空ける** — **フィルター** を空にして、インデックス済みのすべての項目を表示します。**サイズ** の見出しを（必要ならもう一度）クリックし、最大の項目が上に来るようにして、上から順に確認します。不要な項目は `Shift+Delete` で削除できます（ごみ箱を経由せず完全に削除されます）。
- **アプリケーションの書き込み先を監視する** — **フィルター** を空にし、**変更日時** の見出しをクリックして、最新の項目が上に来るようにします。監視したいアプリケーションを起動または使用すると、書き込み中のファイルが変更のたびに上へ移動し、**フォルダー** 列で場所を確認できます。ファイルシステムの一部だけを監視する場合は、先に **フィルター** へパスを入力します。
- **ソースファイル内のテキストを検索する** — 例えば `C:\Projects\\ .cs:` でプロジェクト内の `.cs` ファイルに絞り込みます。検索する文字列を **検索** に入力して `Enter` を押します。

## コンテキスト メニュー

コンテキスト メニューは現在の選択に合わせて変化します。

- **アプリで開く** には、選択項目に対応するインストール済みアプリのみが表示されます。ファイルまたはディレクトリがちょうど 2 つのときは、設定された差分ツールが先頭に表示されます。
- **親フォルダーを開く** は、その項目の親フォルダーをエクスプローラーで開きます。
- **パスをコピー** は、選択項目の完全パスをコピーします。
- **7-Zip** は `7zFM.exe` がインストールされているときに表示されます。
- **Zip** は ZIP アーカイブを作成します。
- **7z アーカイブを作成** は `7z.exe` または `7zz.exe` がインストールされているときのみ表示されます。
- **展開** は対応するアーカイブを選択したときに表示されます。
- **ごみ箱へ移動** は復元可能な削除を行います。

### 削除と復元

削除はまず、選択した各ファイルまたはフォルダーを 1 回の高速な操作として試みます。ロック中、アクセス不可、その他の理由で削除できない項目がフォルダー全体の操作を妨げる場合、File Search Manager は削除可能な最大のサブツリー、続いて個別のファイルへと処理を進めます。それでも削除できない項目 — およびそれらを保持するために必要な親フォルダー — は元の場所に残ります。エラーは、到達可能なすべての同階層の項目を試した後に報告されます。

`Delete` は正常に処理された各項目をごみ箱へ送り、属性と元の場所を保持します。一部だけ処理された場合、無傷のサブフォルダーは可能な限りまとめて保たれ、妨げられた部分のみが分割されるため、ごみ箱の項目が複数に分かれて見えることがあります。各項目を元のパスへ戻すには、ごみ箱の項目を手動でコピーするのではなく、ごみ箱の **元に戻す** コマンドを使用してください。

`Shift+Delete` は同じ手順をとりますが、完全に削除します。必要な箇所では `読み取り専用` 属性を解除します。この動作は一般的なもので、Git リポジトリに限りません。削除がロックされているファイルや、ファイルシステムのアクセス許可で拒否されたパスは残り、最終的なエラー報告に含まれます。

ディレクトリへのドロップと `Ctrl+V` では操作の選択が表示されます。既存の名前と競合した場合は、上書き、スキップ、自動的な名前変更、すべてに適用が選べます。転送は項目ごとの進行状況を表示し、最上位の操作の合間に中止できます。

## 宛先バスケット

下部の宛先バスケットには、繰り返し使えるドロップ先が保持されます。

- **+ 名前** は名前列の選択項目を追加します。フォルダー、対応アーカイブ、実行可能ファイルには、宛先の種類ごとの動作があります。
- **+ フォルダー** は選択項目の親フォルダーを追加します。
- ドラッグ中、バーには 2 つの大きなドロップ領域 **＋ 宛先として追加** と **📤 すべての宛先 (n) に送信** が表示されます。結果一覧でドラッグが始まるか、外部からのドラッグがバーの上に来ると現れ、ドラッグが終わると消えます。
- **宛先として追加** は、そのドラッグが生成したパスをそのまま追加します。したがってフォルダー列で始めたドラッグは親フォルダーを、名前列で始めたドラッグは指定した項目を追加します。宛先チップの後ろの空き領域にドロップしても宛先が追加されます。
- **すべての宛先に送信** は、必要に応じて概要を表示したうえで、利用可能なすべての宛先を使います。チップに直接ドロップした場合は、その宛先だけを使います。
- フォルダーの宛先では、コピー、移動、シンボリック リンク、ハード リンクの選択が表示されます。
- アーカイブの宛先では、ソースがアーカイブに追加されます。ZIP 以外の形式を更新するには `7z.exe` または `7zz.exe` のインストールが必要です。
- 実行可能ファイルの宛先は、ソースのパスを引数として起動され、確認を求めます。
- **クリップボードをすべて (n) に送信…** は、ソースをクリップボードにした同じ操作です。宛先が 1 つも設定されていない間は無効です。
- 宛先をダブルクリックすると開きます。宛先を右クリックすると、その宛先に絞り込む、開く、削除する、すべての宛先を消去する、が選べます。バーの背景を右クリックしても **宛先をクリア** が表示されます。

バスケットはアプリの実行間で自動的に保存されます。見つからない宛先は保存された構成に残りますが、再び利用可能になるまでスキップされます。

宛先とフィルターのコマンドはすべて `Alt` の下にあり、ウィンドウ内のどこでも同じように動作します。`Alt` を押したままにすると **ヒント** パネルに表示され、続いて `N`（選択した名前を宛先として追加）、`F`（親フォルダーを追加）、`V`（クリップボードをすべての宛先へ送信 — 押したまま `L`/`H`/`O` を足すとリンク、ハード リンク、上書き）、`C`（宛先をクリア）、`P`（フィルターを固定）、`I`/`E`（固定フィルターと宛先のインポート／エクスポート）を押します。キー シーケンスは選んだ操作で直接転送します。操作の選択ダイアログが開くのは、ツールバーのボタンとマウスのドロップだけです。

キー シーケンスが有効な間、**ヒント** には有効な次のキーだけが表示されます。`Esc` は、押しているキーを離すと操作が実行され、かつ `Alt` が押されていない場合にのみ提示されます。これは、`Alt` のシーケンスで別のシーケンス キーを押したまま `Alt` を離した後にも当てはまります。`Backspace` は常に 1 段階戻ります。フロー制御はコマンドの選択肢と線で区切られています。

末尾が `›` の項目には、さらに下の階層の選択肢があります。シーケンス キーを押したままそのキーを押すと、サブメニューが表示されます。

結果一覧にフォーカスがあるとき、`T` のキー シーケンスでも宛先を管理できます。`T` は選択項目を宛先として追加、`T` `F` はその親フォルダーを追加、`T` `V` はクリップボードをすべての宛先へ送信、`T` `C` は宛先をクリアします。`T` `V` は `V` と同じ修飾キーを受け付けます。`L` はシンボリック リンク、`H` はハード リンクとして送信し、`O` は既存のファイルを上書きします。

## キーボード コマンド

結果一覧にフォーカスを移し、**ヒント** パネルに表示されたキーを押します。一部のコマンドはキーを押している間は続き、すべて離すと完了します。

よく使うコマンド:

- `Enter`: 選択したフォルダーに絞り込みます。
- `Delete`: 確認のうえ、選択項目をごみ箱へ移動します。
- `Shift+Delete`: 確認なしで選択項目を完全に削除します。
- `Ctrl+C`: シェル互換の標準的なコピー。
- `Ctrl+X`: シェル互換の標準的な切り取り。
- `Ctrl+V`: コピー、移動、シンボリック リンク、ハード リンクを選んで貼り付けます。
- `C`: 選択項目をクリップボードにコピーします。`V`、`T`、`W`、`A` を加えると、代わりにファイルのバージョン、作成日時、最終更新日時、最終アクセス日時をコピーします。先に `+` を押すと、置き換えではなくクリップボードに追加します。
- `X`: 選択項目をクリップボードに切り取ります。
- `D`: 設定された差分ツールで比較します。項目をちょうど 2 つ選択しているときのみ使えます。
- `V`: クリップボードのファイルを、選択したフォルダーまたは親フォルダーに貼り付けます。
- `O`: 選択項目を別のアプリで開きます。
- `A`: 選択項目を管理者として開きます。
- `F2`: 物理的なファイルまたはフォルダー 1 つを、名前セル上で直接リネームします。複数項目の場合は、以下の変換コマンドを使います。
- `F3`: 選択項目を表示します。
- `F4`: 選択項目を編集します。
- `N`: 選択した名前をコピーします。
- `P`: 選択した完全パスをコピーします。
- `F`: 選択したフォルダーのパスをコピーします。
- `M`: 選択したフォルダー内にディレクトリを作成するための入力バーを表示します。
- `S`: 選択コマンド。
- `T`: 宛先コマンド — 選択項目を宛先として追加。続いて `F` で親フォルダー、`V` でクリップボードをすべての宛先へ送信（`L`/`H`/`O` でリンク、ハード リンク、上書き）、`C` で宛先をクリア。
- `U`: 選択したアーカイブを展開します。`NumPad7` を加えると、内蔵処理ではなく `7z.exe` を呼び出します。
- `Z`: 選択項目を圧縮します。`NumPad7` を加えると `7z.exe` を呼び出します。
- `F1`: このヘルプ ファイルを開きます。ウィンドウ内のどこでも使えます。
- `F12`: NTFS から更新します。ウィンドウ内のどこでも使え、選択は不要です。各ドライブは独立して更新されるため、低速なネットワーク ドライブが他を遅らせることはありません。結果グリッドにフォーカスがあるとき、`F1` と `F12` は **ヒント** に表示されたままになります。
- `Right Shift`: フォーカスをフィルター欄に戻します。

`Ctrl` の下のコマンド:

- `Ctrl+A`: すべて選択または選択解除。
- `Ctrl+D`: 選択項目の親フォルダーに絞り込みます。
- `Ctrl+F`: 選択したフォルダーに絞り込みます。
- `Ctrl+N`: 選択したフォルダー内に新しいフォルダーを作成します。
- `Ctrl+J`: 次の選択項目へ移動します。`Ctrl+Shift+J` は前の項目へ移動します。

`O` または `A` の後に選ぶ起動先。各項目は、そのアプリが検出された場合にのみ表示されます。

- `B`: エクスプローラー。
- `W`: 検出された既定の Web ブラウザー。
- `C`: Chrome。
- `F`: Firefox。
- `E`: Edge。
- `O`: Opera。
- `I`: Internet Explorer。
- `A`: Adobe Reader。
- `T`: テキスト ビューアー。
- `D`: Visual Studio Code。
- `V`: Visual Studio。
- `Y`: Antigravity。
- `G`: Ghostscript。
- `P`: GhostPCL。
- `X`: GhostXPS。
- `R`: PRN の内容に対して検出されたビューアー。
- `S` の後に `P`: PowerShell。
- `S` のみ: コマンド プロンプト。

`G`、`P`、`X`、`R` は実行前に DPI の値を尋ねます。

`S` の後の選択コマンド:

- `A`: すべて選択または選択解除。
- `D`: ディレクトリを選択。
- `F`: ファイルを選択。
- `I`: 選択を反転。
- `G`: 緑の行を選択。
- `R`: 赤の行を選択。
- `B`: 黒の行を選択。

`F2` の後の名前変更・変更コマンド:

- `V`: 新しいパスまたは名前をクリップボードから取得。
- `N`: 名前を変更。
- `E`: 拡張子を変更。`E` の後に `Delete` で拡張子を削除。
- `.`: 拡張子を追加。
- `Delete`: 名前からテキストを削除。
- `F`: 接頭辞を追加。
- `L`: 接尾辞を追加。
- `Insert`: 指定位置にテキストを挿入。
- `R`: テキストを置換。
- `C`: 作成日時を変更。続いて `V` でクリップボードの日時、`C` で現在の日時。
- `W`: 最終更新日時を変更。`V` と `C` の選択は同じです。
- `A`: 最終アクセス日時を変更。`V` と `C` の選択は同じです。
- 対応している場合、先に `O` を付けると既存の対象を上書きします。

書き込みが保護された項目（たとえば `Program Files` や `Windows` 配下のもの）に対する名前変更と日時の変更は、権限昇格ヘルパー経由で自動的に再試行されます。ヘルパーがまだ起動していない場合は、そのときに UAC の確認が表示されます。

## データとトラブルシューティング

ユーザーの状態は次の場所に保存されます。

```text
%LOCALAPPDATA%\win-search
```

NTFS の読み込みが遅い場合は、インストーラーからサービスをインストールするか（既定で選択されています）、権限昇格の確認を承認してください。各ドライブがサービス、直接アクセス、管理者ヘルパー、フォルダー巡回のどれを使ったかは、ステータスバーに表示されます。

割り当てられたドライブや外付けドライブが利用できない場合、File Search Manager は短い準備確認の後にそれをスキップし、到達できないストレージで起動が止まらないようにします。
