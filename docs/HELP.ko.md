# File Search Manager 도움말

File Search Manager에는 두 개의 주요 입력란이 있습니다.

- **필터**는 이름, 폴더, 경로 또는 선택한 디렉터리를 기준으로 파일 목록을 좁힙니다.
- **검색**은 현재 필터된 파일들의 내용을 검색합니다.

결과 목록은 키보드 사용을 전제로 설계되었습니다. 목록에 포커스가 있으면 **힌트** 패널에 현재 선택 항목에 사용할 수 있는 명령이 표시됩니다.

## 색인과 권한 상승

시작할 때 File Search Manager는 준비된 드라이브를 로드하고 파일 시스템 변경을 감시합니다. 각 드라이브는 독립적으로 로드되므로 느린 네트워크 드라이브가 다른 드라이브를 지연시키지 않습니다.

기본적으로 NTFS 드라이브만 색인합니다. 다른 파일 시스템(네트워크 연결, FAT USB 메모리)은 빠른 MFT 읽기를 사용할 수 없고, 파일을 하나씩 훑으면 전체 로드를 좌우할 수 있기 때문입니다. 상태 표시줄의 **💽 드라이브…** 단추로 색인할 드라이브를 정확히 선택할 수 있습니다. 선택 해제한 드라이브는 검사도 감시도 하지 않습니다.

NTFS 드라이브에서는 NTFS 마스터 파일 테이블을 읽는 것이 가장 빠릅니다. File Search Manager는 다음 중 한 가지 방법으로 이를 수행합니다.

- Windows 서비스: 확인 요청이 전혀 없습니다. 설치 관리자에서 기본으로 선택되어 있습니다. 이미 설치된 버전의 설치 관리자를 실행하면 **설정 변경**을 선택하여 나머지를 다시 설치하지 않고 서비스를 추가하거나 제거할 수 있습니다.
- 권한 상승 도우미: 앱 실행마다 UAC 확인 한 번. 서비스가 없으면 시작할 때 제안되어 색인을 즉시 시작할 수 있습니다. 서비스가 있으면 관리자 권한이 실제로 필요한 첫 작업 — `A` 키, 관리자만 읽을 수 있는 파일 읽기, 쓰기가 보호된 항목의 이름 바꾸기와 시간 변경 — 까지 제안되지 않습니다. **🌐** 옆의 **🛡** 단추를 사용하면 대신 시작할 때 묻습니다.
- 직접 권한을 올린 앱: File Search Manager를 관리자 권한으로 실행합니다.

이 중 아무것도 사용할 수 없으면 File Search Manager는 폴더 검색으로 전환합니다. 앱은 계속 동작하지만 처음 로드가 느려질 수 있습니다.

서비스는 색인을 위해 읽기 전용으로 동작합니다. MFT 데이터를 데스크톱 앱에 제공하며 이름은 `WinSearchService`입니다.

## 필터 구문

필터 항목은 공백으로 구분합니다. 공백이 포함된 항목이나 경로는 따옴표로 묶습니다.

이름 일치:

- `report`는 `report`를 포함하는 이름과 일치합니다.
- `:report`는 `report`로 시작하는 이름과 일치합니다.
- `report:`는 `report`로 끝나는 이름과 일치합니다.
- `:report:`는 이름이 정확히 `report`인 항목과 일치합니다.
- `.pdf:|.docx:`는 `.pdf` 또는 `.docx`로 끝나는 이름과 일치합니다.
- 여러 항목은 AND로 결합되므로 `report .pdf:`는 `report`를 포함하고 `.pdf`로 끝나는 이름을 찾습니다.

폴더 일치:

- `src\`는 바로 위 부모 폴더 이름이 `src`인 항목과 일치합니다.
- `src\\`는 전체 경로 어디에든 `src`가 있는 항목과 일치합니다.
- 이름 앵커는 경로의 각 구성 요소에 적용되므로 `:src:\\`는 경로의 어느 위치에 있든 이름이 정확히 `src`인 폴더가 포함된 항목을 찾습니다.
- `"C:\Work"`는 `C:\Work` 바로 아래 항목과 일치합니다.
- `"C:\Work\\"`는 `C:\Work` 하위 항목과 재귀적으로 일치합니다.

기록:

- `Ctrl+Left`와 `Ctrl+Right`로 필터 기록을 이동합니다.
- `Down`으로 제안을 엽니다.
- `Del`로 선택한 제안을 삭제합니다.
- 제안을 열 때 `Ctrl`을 누르고 있으면 가장 많이 쓴 기록 대신 최신 기록을 사용합니다.

### 고정된 필터

- **📌 고정…**을 클릭하면 고정된 필터 줄에 편집 가능한 탭이 추가됩니다. 그 자리에서 이름을 입력하고 `Enter`를 누릅니다. `Esc`는 취소합니다.
- 이름이 지정된 필터를 클릭하면 저장된 식이 복원됩니다. 활성 상태인 필터는 강조 표시됩니다.
- 이름이 지정된 필터를 마우스 오른쪽 단추로 클릭하면 현재 식으로 업데이트하거나, 그 자리에서 이름을 바꾸거나, 고정을 해제할 수 있습니다.
- 고정된 필터는 앱이 시작될 때 복원됩니다.

**내보내기…**는 모든 고정된 필터와 대상 바구니 항목을 하나의 JSON 설정 파일로 저장합니다. **가져오기…**는 설정 파일을 검사하고 확인을 거쳐 현재의 고정된 필터와 대상을 그 내용으로 대체합니다.

## 내용 검색

**검색**에 검색어를 입력하고 `Enter`를 누릅니다.

인코딩 옵션:

- `UTF-8`은 UTF-8로 인코딩된 텍스트를 검색합니다.
- `UTF-16`은 UTF-16 리틀 엔디안으로 인코딩된 텍스트를 검색합니다.
- `HEX`는 공백으로 구분된 16진수 바이트를 검색합니다. 예: `48 65 6C 6C 6F`.

**대/소문자 구분 안 함** 확인란은 텍스트 검색에 적용됩니다.

내용 검색 후 결과 색상:

- 녹색: 내용을 찾았습니다.
- 빨강: 내용을 찾지 못했습니다.
- 검정: 항목을 검색하지 않았거나 검색이 지워졌습니다.
- 파랑: 폴더.

검색란에 `Enter` 이외의 것을 입력하면 현재 내용 검색 결과 상태가 지워집니다.

## 마우스 동작

- 결과를 클릭, Ctrl+클릭, Shift+클릭하여 개별 항목이나 범위를 선택합니다.
- 파일이나 폴더 이름을 두 번 클릭하면 해당 항목으로 필터링합니다.
- 폴더 열을 두 번 클릭하면 해당 항목이 선택된 상태로 파일 탐색기가 열립니다.
- 결과를 Ctrl + 마우스 오른쪽 단추로 클릭하면 Windows 기본 동작으로 엽니다.
- 열 머리글을 클릭하면 해당 열을 기준으로 정렬합니다.
- 선택 항목을 마우스 오른쪽 단추로 클릭하면 열기, 동적 연결 프로그램으로 열기, 클립보드, 이름 바꾸기, 압축, 삭제 동작이 표시됩니다.
- **대상 바구니에 추가**는 마우스 오른쪽 단추로 클릭한 열을 따릅니다. 이름이면 선택 항목을, 폴더면 그 부모 폴더를 추가합니다. 해당 경로가 지원되는 대상이 아니거나 이미 바구니에 있으면 숨겨집니다.
- 이름 열에서 끌면 선택한 파일이나 디렉터리를 다른 앱으로 보냅니다.
- 폴더 열에서 끌면 선택 항목의 부모 폴더를 보냅니다.
- 이름 열의 디렉터리나 폴더 열의 부모 경로에 파일을 놓을 수 있습니다. 복사, 이동, 심볼릭 링크, 하드 링크 중에서 선택합니다.
- 실행 파일인 이름 셀에 파일을 놓으면 놓은 경로를 인수로 하여 실행합니다.
- 파일 놓기는 탐색기 기본값을 따릅니다. 같은 볼륨의 폴더 하나면 이동, 다른 볼륨이면 복사입니다. `Ctrl`은 복사, `Shift`는 이동, `Alt`는 심볼릭 링크입니다. 대상이 여러 개면 복사가 됩니다.

## 실용적인 예

- **디스크 공간 확보** — **필터**를 비워 색인된 모든 항목을 표시합니다. **크기** 열 머리글을 (필요하면 다시) 클릭해 가장 큰 항목이 위에 오도록 한 다음 위에서부터 목록을 검토하고, 필요 없는 항목은 `Shift+Delete`로 삭제합니다(휴지통을 거치지 않고 영구 삭제).
- **애플리케이션의 기록 위치 실시간 확인** — **필터**를 비우고 **변경됨** 열 머리글을 클릭해 가장 최근에 변경된 항목이 위에 오도록 합니다. 관찰할 애플리케이션을 시작하거나 사용하면, 애플리케이션이 기록하는 파일이 변경될 때마다 위로 이동하고 **폴더** 열에서 위치를 확인할 수 있습니다. 파일 시스템의 일부만 관찰하려면 먼저 **필터**에 경로를 입력합니다.
- **소스 파일에서 텍스트 검색** — 예를 들어 `C:\Projects\\ .cs:`를 사용해 프로젝트의 `.cs` 파일로 결과를 제한합니다. 찾을 텍스트를 **검색**에 입력하고 `Enter`를 누릅니다.

## 상황에 맞는 메뉴

상황에 맞는 메뉴는 현재 선택에 따라 달라집니다.

- **연결 프로그램으로 열기**에는 선택 항목과 호환되는 설치된 앱만 표시됩니다. 파일이나 디렉터리가 정확히 두 개일 때는 설정된 비교 도구가 맨 앞에 표시됩니다.
- **포함된 폴더 열기**는 해당 항목의 부모 폴더를 파일 탐색기로 엽니다.
- **경로 복사**는 선택 항목의 전체 경로를 복사합니다.
- **7-Zip**은 `7zFM.exe`가 설치되어 있을 때 표시됩니다.
- **압축**은 ZIP 아카이브를 만듭니다.
- **7z 아카이브 만들기**는 `7z.exe` 또는 `7zz.exe`가 설치되어 있을 때만 표시됩니다.
- **압축 풀기**는 지원되는 아카이브를 선택했을 때 표시됩니다.
- **휴지통으로 이동**은 복원 가능한 삭제를 수행합니다.

### 삭제 및 복원

삭제는 먼저 선택한 각 파일이나 폴더를 한 번의 빠른 작업으로 시도합니다. 잠겼거나 접근할 수 없거나 그 밖의 이유로 삭제할 수 없는 항목이 폴더 전체 작업을 막으면, File Search Manager는 삭제 가능한 가장 큰 하위 트리부터, 그다음 개별 파일로 처리를 이어갑니다. 그래도 삭제할 수 없는 항목과 이를 담는 데 필요한 부모 폴더는 원래 위치에 남습니다. 오류는 접근 가능한 같은 수준의 항목을 모두 시도한 뒤에 보고됩니다.

`Delete`는 성공적으로 처리된 각 항목을 휴지통으로 보내며 특성과 원래 위치를 유지합니다. 일부만 처리된 경우, 손상되지 않은 하위 폴더는 가능한 한 함께 유지되고 막힌 부분만 더 나뉘므로 휴지통 항목이 여러 개로 보일 수 있습니다. 각 항목을 원래 경로로 되돌리려면 휴지통 항목을 수동으로 복사하지 말고 휴지통의 **복원** 명령을 사용하세요.

`Shift+Delete`는 같은 방식으로 처리하되 영구 삭제합니다. 필요한 곳에서는 `읽기 전용` 특성을 제거합니다. 이 동작은 일반적인 것으로 Git 저장소에만 국한되지 않습니다. 삭제가 잠긴 파일과 파일 시스템 권한으로 거부된 경로는 남으며 최종 오류 보고에 포함됩니다.

디렉터리에 놓기와 `Ctrl+V`는 작업 선택을 표시합니다. 기존 이름과 충돌하면 덮어쓰기, 건너뛰기, 자동 이름 바꾸기, 모두 적용을 선택할 수 있습니다. 전송은 항목별 진행률을 표시하며 최상위 작업 사이에 취소할 수 있습니다.

## 대상 바구니

아래쪽 대상 바구니에는 재사용 가능한 놓기 대상이 유지됩니다.

- **+ 이름**은 이름 열의 선택 항목을 추가합니다. 폴더, 지원되는 아카이브, 실행 파일에는 대상 종류별 동작이 있습니다.
- **+ 폴더**는 선택 항목의 부모 폴더를 추가합니다.
- 끌기 중에는 막대에 두 개의 큰 놓기 영역 **＋ 대상으로 추가**와 **📤 모든 대상 (n)으로 보내기**가 표시됩니다. 결과 목록에서 끌기가 시작되거나 외부 끌기가 막대 위에 오면 나타나고, 끌기가 끝나면 사라집니다.
- **대상으로 추가**는 그 끌기가 만들어 낸 경로를 그대로 추가합니다. 따라서 폴더 열에서 시작한 끌기는 부모 폴더를, 이름 열에서 시작한 끌기는 지정된 항목을 추가합니다. 대상 칩 뒤의 빈 공간에 놓아도 대상이 추가됩니다.
- **모든 대상으로 보내기**는 필요하면 요약을 표시한 뒤 사용 가능한 모든 대상을 사용합니다. 칩에 직접 놓으면 그 대상만 사용합니다.
- 폴더 대상에서는 복사, 이동, 심볼릭 링크, 하드 링크 선택이 표시됩니다.
- 아카이브 대상은 원본을 아카이브에 추가합니다. ZIP 이외의 형식을 갱신하려면 `7z.exe` 또는 `7zz.exe`가 설치되어 있어야 합니다.
- 실행 파일 대상은 원본 경로를 인수로 하여 시작되며 확인이 필요합니다.
- **클립보드를 모든 대상 (n)으로 보내기…**는 클립보드를 원본으로 하는 같은 작업입니다. 대상이 하나도 설정되지 않은 동안에는 사용할 수 없습니다.
- 대상을 두 번 클릭하면 열립니다. 대상을 마우스 오른쪽 단추로 클릭하면 그 대상으로 필터링, 열기, 제거, 모든 대상 지우기를 할 수 있습니다. 막대 배경을 마우스 오른쪽 단추로 클릭해도 **대상 지우기**가 표시됩니다.

바구니는 앱 실행 사이에 자동으로 저장됩니다. 없는 대상은 저장된 구성에 남아 있지만 다시 사용할 수 있게 될 때까지 건너뜁니다.

모든 대상 및 필터 명령은 `Alt` 아래에 있으며 창 어디에서나 동일하게 동작합니다. `Alt`를 누르고 있으면 **힌트** 패널에 표시되며, 이어서 `N`(선택한 이름을 대상으로 추가), `F`(부모 폴더 추가), `V`(클립보드를 모든 대상으로 보내기 — 계속 누른 채 `L`/`H`/`O`를 더하면 링크, 하드 링크, 덮어쓰기), `C`(대상 지우기), `P`(필터 고정), `I`/`E`(고정된 필터와 대상 가져오기/내보내기)를 누릅니다. 키 시퀀스는 선택한 동작으로 바로 전송합니다. 동작 선택 대화 상자는 도구 모음 단추와 마우스 놓기에서만 열립니다.

키 시퀀스가 활성 상태인 동안 **힌트**에는 유효한 다음 키만 표시됩니다. `Esc`는 누르고 있는 키를 놓으면 동작이 실행되고 `Alt`를 누르고 있지 않을 때만 제공됩니다. 다른 시퀀스 키를 누른 채 `Alt`를 놓은 뒤의 `Alt` 시퀀스에서도 동일합니다. `Backspace`는 항상 한 단계 뒤로 갑니다. 흐름 제어는 명령 선택지와 선으로 구분됩니다.

`›`로 끝나는 항목에는 다음 단계의 선택지가 있습니다. 시퀀스 키를 누른 채 그 키를 누르면 하위 메뉴가 표시됩니다.

결과 목록에 포커스가 있으면 `T` 키 시퀀스로도 대상을 관리합니다. `T`는 선택 항목을 대상으로 추가하고, `T` `F`는 그 부모 폴더를 추가하며, `T` `V`는 클립보드를 모든 대상으로 보내고, `T` `C`는 대상을 지웁니다. `T` `V`는 `V`와 같은 한정 키를 받습니다. `L`은 심볼릭 링크, `H`는 하드 링크로 보내고 `O`는 기존 파일을 덮어씁니다.

## 키보드 명령

결과 목록에 포커스를 두고 **힌트** 패널에 표시된 키를 누릅니다. 일부 명령은 키를 누르고 있는 동안 계속되며 모두 놓으면 완료됩니다.

자주 쓰는 명령:

- `Enter`: 선택한 폴더로 필터링합니다.
- `Delete`: 확인 후 선택 항목을 휴지통으로 이동합니다.
- `Shift+Delete`: 확인 없이 선택 항목을 영구 삭제합니다.
- `Ctrl+C`: 셸과 호환되는 표준 복사.
- `Ctrl+X`: 셸과 호환되는 표준 잘라내기.
- `Ctrl+V`: 복사, 이동, 심볼릭 링크, 하드 링크를 선택한 뒤 붙여넣습니다.
- `C`: 선택 항목을 클립보드로 복사합니다. `V`, `T`, `W`, `A`를 더하면 대신 파일 버전, 만든 시간, 마지막 쓴 시간, 마지막 액세스 시간을 복사합니다. 앞에 `+`를 누르면 클립보드를 바꾸지 않고 덧붙입니다.
- `X`: 선택 항목을 클립보드로 잘라냅니다.
- `D`: 설정된 비교 도구로 비교합니다. 항목을 정확히 두 개 선택했을 때만 사용할 수 있습니다.
- `V`: 클립보드의 파일을 선택한 폴더나 부모 폴더에 붙여넣습니다.
- `O`: 선택 항목을 다른 앱에서 엽니다.
- `A`: 선택 항목을 관리자 권한으로 엽니다.
- `F2`: 실제 파일이나 폴더 하나를 이름 셀에서 바로 이름 바꿉니다. 항목이 여러 개일 때는 아래의 변환 명령을 사용합니다.
- `F3`: 선택 항목을 봅니다.
- `F4`: 선택 항목을 편집합니다.
- `N`: 선택한 이름을 복사합니다.
- `P`: 선택한 전체 경로를 복사합니다.
- `F`: 선택한 폴더 경로를 복사합니다.
- `M`: 선택한 폴더에 디렉터리를 만들기 위한 입력 막대를 표시합니다.
- `S`: 선택 명령.
- `T`: 대상 명령 — 선택 항목을 대상으로 추가. 이어서 `F`는 부모 폴더, `V`는 클립보드를 모든 대상으로 보내기(`L`/`H`/`O`는 링크, 하드 링크, 덮어쓰기), `C`는 대상 지우기.
- `U`: 선택한 아카이브의 압축을 풉니다. `NumPad7`을 더하면 내장 처리 대신 `7z.exe`를 호출합니다.
- `Z`: 선택 항목을 압축합니다. `NumPad7`을 더하면 `7z.exe`를 호출합니다.
- `F1`: 이 도움말 파일을 엽니다. 창 어디에서나 동작합니다.
- `F12`: NTFS에서 새로 고칩니다. 창 어디에서나 동작하며 선택이 필요 없습니다. 각 드라이브는 독립적으로 새로 고쳐지므로 느린 네트워크 드라이브가 다른 드라이브를 지연시키지 않습니다. 결과 표에 포커스가 있으면 `F1`과 `F12`는 **힌트**에 계속 표시됩니다.
- `Right Shift`: 포커스를 필터 입력란으로 되돌립니다.

`Ctrl` 아래의 명령:

- `Ctrl+A`: 전체 선택 또는 선택 해제.
- `Ctrl+D`: 선택 항목의 부모 폴더로 필터링합니다.
- `Ctrl+F`: 선택한 폴더로 필터링합니다.
- `Ctrl+N`: 선택한 폴더 안에 새 폴더를 만듭니다.
- `Ctrl+J`: 다음 선택 항목으로 이동합니다. `Ctrl+Shift+J`는 이전 항목으로 이동합니다.

`O` 또는 `A` 다음의 열기 대상. 각 항목은 해당 앱이 감지된 경우에만 표시됩니다.

- `B`: 파일 탐색기.
- `W`: 감지된 기본 웹 브라우저.
- `C`: Chrome.
- `F`: Firefox.
- `E`: Edge.
- `O`: Opera.
- `I`: Internet Explorer.
- `A`: Adobe Reader.
- `T`: 텍스트 뷰어.
- `D`: Visual Studio Code.
- `V`: Visual Studio.
- `Y`: Antigravity.
- `G`: Ghostscript.
- `P`: GhostPCL.
- `X`: GhostXPS.
- `R`: PRN 콘텐츠용으로 감지된 뷰어.
- `S` 다음 `P`: PowerShell.
- `S` 단독: 명령 프롬프트.

`G`, `P`, `X`, `R`은 실행 전에 DPI 값을 묻습니다.

`S` 다음의 선택 명령:

- `A`: 전체 선택 또는 선택 해제.
- `D`: 디렉터리 선택.
- `F`: 파일 선택.
- `I`: 선택 반전.
- `G`: 녹색 행 선택.
- `R`: 빨간색 행 선택.
- `B`: 검은색 행 선택.

`F2` 다음의 이름 바꾸기/변경 명령:

- `V`: 새 경로나 이름을 클립보드에서 가져오기.
- `N`: 이름 변경.
- `E`: 확장명 변경. `E` 다음 `Delete`는 확장명을 제거합니다.
- `.`: 확장명 추가.
- `Delete`: 이름에서 텍스트 삭제.
- `F`: 접두사 추가.
- `L`: 접미사 추가.
- `Insert`: 지정 위치에 텍스트 삽입.
- `R`: 텍스트 바꾸기.
- `C`: 만든 시간 변경. 이어서 `V`는 클립보드의 시간, `C`는 현재 시간입니다.
- `W`: 마지막 쓴 시간 변경. `V`와 `C` 선택은 동일합니다.
- `A`: 마지막 액세스 시간 변경. `V`와 `C` 선택은 동일합니다.
- 지원되는 경우 앞에 `O`를 더하면 기존 대상을 덮어씁니다.

쓰기가 보호된 항목(예: `Program Files`나 `Windows` 아래의 모든 것)에 대한 이름 바꾸기와 시간 변경은 권한 상승 도우미를 통해 자동으로 다시 시도됩니다. 도우미가 아직 실행되지 않았다면 그때 UAC 확인이 표시됩니다.

## 데이터 및 문제 해결

사용자 상태는 다음 위치에 저장됩니다.

```text
%LOCALAPPDATA%\win-search
```

NTFS 로드가 느리면 설치 관리자에서 서비스를 설치하거나(기본으로 선택되어 있습니다) 권한 상승 요청을 승인하세요. 각 드라이브가 서비스, 직접 액세스, 관리자 도우미, 폴더 검색 중 무엇을 사용했는지는 상태 표시줄에 표시됩니다.

연결된 드라이브나 외장 드라이브를 사용할 수 없으면 File Search Manager는 짧은 준비 확인 후 건너뛰어, 도달할 수 없는 저장소에서 시작이 멈추지 않도록 합니다.
