# File Search Manager 帮助

File Search Manager 有两个主要输入框：

- **筛选** 按名称、文件夹、路径或选定目录缩小文件列表。
- **搜索** 在当前已筛选的文件中搜索文件内容。

结果列表是为键盘操作设计的。当列表获得焦点时，**提示** 面板会显示当前选择可用的命令。

## 索引和权限提升

启动时，File Search Manager 会加载已就绪的驱动器并监视文件系统变化。每个驱动器独立加载，因此速度较慢的网络驱动器绝不会拖慢其他驱动器。

默认只索引 NTFS 驱动器：其他文件系统（网络映射、FAT 优盘）无法使用快速的 MFT 读取，逐个文件遍历可能占据整个加载过程。使用状态栏中的 **💽 磁盘…** 按钮可以精确选择要索引的驱动器；未勾选的驱动器既不扫描也不监视。

对于 NTFS 驱动器，最快的方式是读取 NTFS 主文件表。File Search Manager 可以通过以下方式之一实现：

- Windows 服务：完全没有提示。在安装程序中默认已选中。运行已安装版本的安装程序会提供 **Modify settings**（修改设置，安装向导对简体中文显示英文），可在不重新安装其余部分的情况下添加或删除该服务。
- 提权助手：每次运行应用一次 UAC 提示。没有服务时会在启动时提出，以便索引立即开始。有服务时，直到第一个确实需要管理员权限的操作才会提出——`A` 键、读取仅管理员可访问的文件，或对写入受保护项目进行重命名和时间更改。**🌐** 旁边的 **🛡** 按钮可改为在启动时询问。
- 直接以管理员身份运行：以管理员身份启动 File Search Manager。

如果以上方式都不可用，File Search Manager 会退回到遍历文件夹。应用仍可使用，但首次加载可能较慢。

该服务在索引方面为只读。它向桌面应用提供 MFT 数据，名称为 `WinSearchService`。

## 筛选语法

筛选词以空格分隔。包含空格的词或路径请加引号。

名称匹配：

- `report` 匹配包含 `report` 的名称。
- `:report` 匹配以 `report` 开头的名称。
- `report:` 匹配以 `report` 结尾的名称。
- `:report:` 匹配名称恰为 `report` 的项目。
- `.pdf:|.docx:` 匹配以 `.pdf` 或 `.docx` 结尾的名称。
- 多个词按 AND 组合，因此 `report .pdf:` 会查找包含 `report` 且以 `.pdf` 结尾的名称。

文件夹匹配：

- `src\` 匹配直接父文件夹名为 `src` 的项目。
- `src\\` 匹配完整路径中任意位置含有 `src` 的项目。
- 名称锚点会应用于路径的每个组成部分，因此 `:src:\\` 可匹配路径中任意位置包含名称恰为 `src` 的文件夹的项目。
- `"C:\Work"` 匹配直接位于 `C:\Work` 中的项目。
- `"C:\Work\\"` 递归匹配 `C:\Work` 之下的项目。

历史记录：

- `Ctrl+Left` 和 `Ctrl+Right` 浏览筛选历史。
- `Down` 打开建议。
- `Del` 删除选中的建议。
- 打开建议时按住 `Ctrl`，可使用最近的历史而非最常用的历史。

### 固定的筛选

- 点击 **📌 固定…** 可在固定筛选行中添加一个可编辑的标签页。就地输入名称并按 `Enter`；`Esc` 取消。
- 点击已命名的筛选可恢复其保存的表达式。当前生效的已命名筛选会突出显示。
- 右键点击已命名的筛选，可用当前表达式更新它、就地重命名或取消固定。
- 固定的筛选会在应用启动时恢复。

**导出…** 将所有固定的筛选和目标篮条目保存到单个 JSON 设置文件。**导入…** 会校验设置文件，并在确认后用其内容替换当前的固定筛选和目标。

## 内容搜索

在 **搜索** 中输入内容并按 `Enter`。

编码选项：

- `UTF-8` 搜索以 UTF-8 编码的文本。
- `UTF-16` 搜索以 UTF-16 小端序编码的文本。
- `HEX` 搜索以空格分隔的十六进制字节，例如 `48 65 6C 6C 6F`。

**忽略大小写** 复选框适用于文本搜索。

内容搜索后的结果颜色：

- 绿色：已找到内容。
- 红色：未找到内容。
- 黑色：该项目未被搜索，或搜索已清除。
- 蓝色：文件夹。

在搜索框中输入 `Enter` 以外的任何内容，都会清除当前的内容搜索结果状态。

## 鼠标操作

- 点击、Ctrl+点击或 Shift+点击结果可选择单个项目或范围。
- 双击文件或文件夹名称可筛选进入该项目。
- 双击文件夹列可打开文件资源管理器并选中该项目。
- Ctrl + 右键点击结果，可用 Windows 默认操作打开。
- 点击列标题可按该列排序。
- 右键点击选中项目可使用打开、动态的用其他程序打开、剪贴板、重命名、压缩和删除操作。
- **添加到目标篮** 取决于右键点击的列：名称列添加选中项目，文件夹列添加它们的父文件夹。当对应路径不是受支持的目标或已在篮中时，该项会隐藏。
- 从名称列拖动，可将选中的文件或目录发送到其他应用。
- 从文件夹列拖动，可发送选中项目的父文件夹。
- 可将文件放到名称列中的目录上，或文件夹列中的父路径上。可选择复制、移动、符号链接或硬链接。
- 将文件放到可执行文件的名称单元格上，会以放入的路径作为参数启动它。
- 放置文件遵循资源管理器的默认行为：同一卷上的单个文件夹默认为移动，不同卷默认为复制。按住 `Ctrl` 复制、`Shift` 移动、`Alt` 创建符号链接。多个目标时默认为复制。

## 实用示例

- **释放磁盘空间** — 清空 **筛选** 以显示所有已建立索引的项目。点击 **大小** 列标题（必要时再次点击），直到最大的项目位于顶部，然后从上到下检查列表；使用 `Shift+Delete` 删除不需要的项目（永久删除，不经过回收站）。
- **实时查看应用写入位置** — 清空 **筛选** 并点击 **已更改** 列标题，直到最近修改的项目位于顶部。随后启动或使用要观察的应用；它正在写入的文件会在每次变化后移到顶部，**文件夹** 列会显示位置。如果只想观察文件系统的一部分，请先在 **筛选** 中输入路径。
- **搜索源文件中的文本** — 例如使用 `C:\Projects\\ .cs:` 将结果限制为项目中的 `.cs` 文件。在 **搜索** 框中输入要查找的文本，然后按 `Enter`。

## 右键菜单

右键菜单会随当前选择而变化：

- **用其他程序打开** 只列出与所选内容兼容的已安装应用。当恰好选中两个文件或目录时，已配置的比较工具会排在最前。
- **打开所在文件夹** 会在该项目的父文件夹中打开文件资源管理器。
- **复制路径** 会复制选中项目的完整路径。
- **7-Zip** 在安装了 `7zFM.exe` 时显示。
- **压缩** 创建 ZIP 归档。
- **创建 7z 归档** 仅在安装了 `7z.exe` 或 `7zz.exe` 时显示。
- **解压** 在选中受支持的归档时显示。
- **移到回收站** 执行可恢复的删除。

### 删除和还原

删除会先把每个选中的文件或文件夹作为一次快速操作来尝试。如果某个被锁定、无法访问或因其他原因无法删除的项目阻碍了整个文件夹的操作，File Search Manager 会继续处理可删除的最大子树，然后处理单个文件。仍然无法删除的项目——以及为容纳它们所必需的父文件夹——会保留在原位置。错误会在尝试完所有可访问的同级项目之后报告。

`Delete` 会把每个成功处理的项目送入回收站，并保留其属性和原始位置。部分完成的操作可能显示为多个回收站条目，因为完好的子文件夹会尽可能保持在一起，只有被阻碍的部分才会进一步拆分。要将每个项目还原到原始路径，请使用回收站的 **还原** 命令，而不要手动复制其中的条目。

`Shift+Delete` 采用相同的处理方式，但为永久删除。它会在必要处清除 `只读` 属性；此行为是通用的，并不限于 Git 仓库。被锁定而无法删除的文件，以及因文件系统权限被拒绝的路径会保留下来，并列入最终的错误报告。

放置目录和 `Ctrl+V` 会显示操作选择。遇到同名冲突时可选择覆盖、跳过、自动重命名以及应用于全部。传输会显示每个项目的进度，并可在顶层操作之间取消。

## 目标篮

底部的目标篮保存可重复使用的放置目标：

- **+ 名称** 添加名称列中的选中项目。文件夹、受支持的归档和可执行文件具有各自的目标行为。
- **+ 文件夹** 添加选中项目的父文件夹。
- 拖动过程中，该栏会显示两个大的放置区域：**＋ 作为目标添加** 和 **📤 发送到所有目标 (n)**。它们在结果列表中开始拖动时，或外部拖动悬停在该栏上时出现，拖动结束后消失。
- **作为目标添加** 会精确添加此次拖动产生的路径。因此从文件夹列开始的拖动添加父文件夹，从名称列开始的拖动添加指定项目。放到目标标记之后的空白处同样会添加目标。
- **发送到所有目标** 会在需要时先显示摘要，然后使用每个可用目标。直接放到某个标记上则只使用该目标。
- 文件夹目标会显示复制、移动、符号链接和硬链接的选择。
- 归档目标会将源添加到归档中。更新 ZIP 以外的格式需要已安装 `7z.exe` 或 `7zz.exe`。
- 可执行文件目标会以源路径作为参数启动，并需要确认。
- **将剪贴板发送到所有目标 (n)…** 是以剪贴板为源的相同操作；在未设置任何目标时不可用。
- 双击目标可打开它。右键点击目标可筛选到它、打开它、移除它或清除所有目标。右键点击该栏的背景同样会提供 **清除目标**。

目标篮会在应用两次运行之间自动保存。缺失的目标仍保留在已保存的配置中，但会被跳过，直到重新可用为止。

所有目标和筛选命令都位于 `Alt` 之下，在窗口中任何位置行为一致：按住 `Alt` 即可在 **提示** 面板中看到它们，然后按 `N`（将选中的名称添加为目标）、`F`（添加父文件夹）、`V`（将剪贴板发送到所有目标——继续按住并加上 `L`/`H`/`O` 表示链接、硬链接、覆盖）、`C`（清除目标）、`P`（固定筛选）、`I`/`E`（导入/导出固定的筛选和目标）。键盘序列会直接按所选操作传输；只有工具栏按钮和鼠标放置才会打开操作选择对话框。

在键盘序列生效期间，**提示** 只显示有效的后续按键。仅当松开所按的键会执行某个操作且当前未按住 `Alt` 时，才会提供 `Esc`。在按住其他序列键的情况下松开 `Alt` 后的 `Alt` 序列中同样如此。`Backspace` 始终后退一步。流程控制与命令选项之间以一条线分隔。

以 `›` 结尾的条目还有下一级命令选项；按住序列键并按下该键即可显示子菜单。

当结果列表获得焦点时，`T` 键序列同样可管理目标：`T` 将选中项目添加为目标，`T` `F` 添加它们的父文件夹，`T` `V` 将剪贴板发送到所有目标，`T` `C` 清除目标。`T` `V` 接受与 `V` 相同的修饰键：`L` 以符号链接发送，`H` 以硬链接发送，`O` 覆盖已有文件。

## 键盘命令

将焦点移到结果列表，然后按 **提示** 面板中显示的按键。某些命令在按住按键期间持续进行，全部松开后完成。

常用命令：

- `Enter`：筛选进入选中的文件夹。
- `Delete`：确认后将选中项目移到回收站。
- `Shift+Delete`：不经确认永久删除选中项目。
- `Ctrl+C`：与外壳兼容的标准复制。
- `Ctrl+X`：与外壳兼容的标准剪切。
- `Ctrl+V`：在选择复制、移动、符号链接或硬链接后粘贴。
- `C`：将选中项目复制到剪贴板。加上 `V`、`T`、`W` 或 `A` 可改为复制文件版本、创建时间、最后写入时间或最后访问时间；先按 `+` 则追加到剪贴板而不是替换。
- `X`：将选中项目剪切到剪贴板。
- `D`：在已配置的比较工具中比较。仅在恰好选中两个项目时可用。
- `V`：将剪贴板中的文件粘贴到选中的文件夹或其父文件夹。
- `O`：在其他应用中打开选中项目。
- `A`：以管理员身份打开选中项目。
- `F2`：在名称单元格中直接重命名单个实际文件或文件夹。选中多个项目时，请使用下面的变换命令。
- `F3`：查看选中项目。
- `F4`：编辑选中项目。
- `N`：复制选中的名称。
- `P`：复制选中的完整路径。
- `F`：复制选中的文件夹路径。
- `M`：显示用于在选中文件夹中创建目录的内嵌输入栏。
- `S`：选择命令。
- `T`：目标命令——将所选内容添加为目标；随后 `F` 表示父文件夹，`V` 表示将剪贴板发送到所有目标（`L`/`H`/`O` 表示链接、硬链接、覆盖），`C` 表示清除目标。
- `U`：解压选中的归档。加上 `NumPad7` 会调用 `7z.exe` 而不是内置处理。
- `Z`：压缩选中项目。加上 `NumPad7` 会调用 `7z.exe`。
- `F1`：打开本帮助文件。在窗口中任何位置均可使用。
- `F12`：从 NTFS 刷新。在窗口中任何位置均可使用，无需选择；每个驱动器独立刷新，因此速度较慢的网络驱动器绝不会拖慢其他驱动器。当结果表格获得焦点时，`F1` 和 `F12` 会持续显示在 **提示** 中。
- `Right Shift`：将焦点移回筛选框。

`Ctrl` 之下的命令：

- `Ctrl+A`：全选或取消全选。
- `Ctrl+D`：筛选进入选中项目的父文件夹。
- `Ctrl+F`：筛选进入选中的文件夹。
- `Ctrl+N`：在选中的文件夹中创建新文件夹。
- `Ctrl+J`：跳到下一个选中项目；`Ctrl+Shift+J` 跳到上一个。

在 `O` 或 `A` 之后的打开目标。每一项仅在检测到相应应用时才会出现：

- `B`：文件资源管理器。
- `W`：检测到的默认网页浏览器。
- `C`：Chrome。
- `F`：Firefox。
- `E`：Edge。
- `O`：Opera。
- `I`：Internet Explorer。
- `A`：Adobe Reader。
- `T`：文本查看器。
- `D`：Visual Studio Code。
- `V`：Visual Studio。
- `Y`：Antigravity。
- `G`：Ghostscript。
- `P`：GhostPCL。
- `X`：GhostXPS。
- `R`：为 PRN 内容检测到的查看器。
- `S` 然后 `P`：PowerShell。
- 单独的 `S`：命令提示符。

`G`、`P`、`X` 和 `R` 在运行前会询问 DPI 数值。

在 `S` 之后的选择命令：

- `A`：全选或取消全选。
- `D`：选择目录。
- `F`：选择文件。
- `I`：反转选择。
- `G`：选择绿色行。
- `R`：选择红色行。
- `B`：选择黑色行。

在 `F2` 之后的重命名/更改命令：

- `V`：从剪贴板取用新的路径或名称。
- `N`：更改名称。
- `E`：更改扩展名；`E` 之后按 `Delete` 可删除扩展名。
- `.`：添加扩展名。
- `Delete`：从名称中删除文本。
- `F`：添加前缀。
- `L`：添加后缀。
- `Insert`：在指定位置插入文本。
- `R`：替换文本。
- `C`：更改创建时间，随后按 `V` 使用剪贴板中的时间，或按 `C` 使用当前时间。
- `W`：更改最后写入时间，同样可选 `V` 和 `C`。
- `A`：更改最后访问时间，同样可选 `V` 和 `C`。
- 在受支持时，先加上 `O` 可覆盖已有目标。

对写入受保护项目（例如 `Program Files` 或 `Windows` 之下的一切）的重命名和时间更改，会自动通过提权助手重试。如果助手尚未启动，UAC 提示就会在此时出现。

## 数据与疑难解答

用户状态保存在：

```text
%LOCALAPPDATA%\win-search
```

如果 NTFS 加载较慢，请从安装程序安装该服务（默认已选中），或批准权限提升提示。状态栏会说明每个驱动器使用的是服务、直接访问、管理员助手还是遍历文件夹。

如果映射驱动器或外部驱动器不可用，File Search Manager 会在短暂的就绪检查后跳过它，以免启动卡在无法访问的存储上。
